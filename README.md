# Planning & Governance Hub — Cổng Thông tin Quản trị Kế hoạch

Website quản trị công việc phong cách **Notion** dành cho **Trợ lý Kế hoạch**, được thiết kế thuần tĩnh (HTML/CSS/ES6 JavaScript) để chạy mượt mà và hoàn toàn miễn phí trên **GitHub Pages** mà không cần cài đặt Node.js hay công cụ build phức tạp.

## Các phân hệ chính
1. **Tổng quan & Điều hành (`#/overview`):** Theo dõi tỷ lệ hoàn thành KPI, cảnh báo đầu mục chậm tiến độ kèm giải pháp tham mưu và lịch chương trình sắp tới.
2. **Quản trị Kế hoạch (`#/plans`):** Quản lý danh sách kế hoạch dưới dạng Bảng (Table) hoặc Bảng thẻ (Kanban), cập nhật % tiến độ, vướng mắc và giải pháp tham mưu.
3. **Quy trình & Quy định (`#/sops`):** Thư viện tài liệu quản trị chuẩn hóa với lưu đồ các bước, thuộc tính phiên bản và checklist kiểm soát tuân thủ tương tác trực tiếp.
4. **Cơ cấu & Chức năng Nhiệm vụ (`#/org`):** Sơ đồ cơ cấu đơn vị tương tác và Ma trận phân công trách nhiệm RACI.
5. **Chuyển đổi số & Chương trình Quản trị (`#/digital`):** Theo dõi sáng kiến chuyển đổi số và lịch triển khai công tác quản trị.
6. **Tìm kiếm nhanh (`Ctrl + K`):** Nhảy tức thì tới bất kỳ kế hoạch, mã quy trình hay bộ phận nào.

## Hướng dẫn Host lên GitHub Pages
Xem chi tiết từng bước (có hướng dẫn kéo-thả trực tiếp trên web không cần gõ lệnh) tại file [`HUONG_DAN_GITHUB.md`](./HUONG_DAN_GITHUB.md) hoặc mở mục **Hướng dẫn Host GitHub** ngay trên thanh bên của website.
